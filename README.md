# Supply-Chain-Analysis
End-to-End Supply Chain Analysis using Python, SQL &amp; Power BI | Data Cleaning | EDA | Dashboard | Business Insights

## Objectives
- Clean and preprocess supply chain data
- Analyze inventory, revenue, transportation costs, and supplier performance
- Perform SQL-based data analysis
- Build interactive Power BI dashboards
- Generate actionable business insights

## Technologies Used
- Python
- Pandas
- NumPy
- SQL (MySQL)
- Power BI
- Jupyter Notebook

## Project Files
- Supply Chain Analysis.ipynb
- Supply Chain SQL.sql
- Dashboard.pbix
- Quality&Manufacturing.pbix
- supply_chain_cleaned.csv
- Project Report
- PowerPoint Presentation

## Key Insights
- Revenue analysis by product type
- Inventory analysis
- Supplier performance evaluation
- Transportation cost analysis
- Defect rate analysis
- Interactive Power BI dashboards

## How to Run
1. Open the Jupyter Notebook.
2. Install required Python libraries.
3. Import the dataset.
4. Execute the notebook.
5. Open the .pbix files in Power BI Desktop to view dashboards.
